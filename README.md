# DeeperSeeker

Реверс-прокси-сервер для сайта DeepSeek на FastAPI с поддержкой стандартов API OpenAI и Anthropic.

Если вы хотите использовать deeperseeker с приложением Claude Desktop, см. [Руководство по настройке Claude Desktop](CLAUDE_DESKTOP_SETUP.md)

Для решения pow-задачи DeepSeek используется wasm-файл из моего другого репозитория: https://github.com/AmanCode22/deepseek_pow_solver/

Если вам понравился этот репозиторий — поставьте звёздочку ему и солверу.

⚠️ Предупреждение: автоматизированное использование нарушает Условия использования DeepSeek.
Используйте отдельный одноразовый аккаунт, никогда не личный.
Аккаунты могут быть заблокированы в любой момент.
Используйте на свой страх и риск.

Просьба: не спамьте сервером, уважайте лимиты DeepSeek и используйте его только в личных целях.

### Заметки по развёртыванию на разных платформах

- **Бесплатные хостинги на базе Pterodactyl** (Wispbyte, HeavenCloud и подобные): панель
  подставляет `SERVER_PORT`, а deeperseeker читает `PORT`, поэтому используйте команду запуска
  `PORT=$SERVER_PORT python app.py`.
- Весь каталог `wasm/` должен быть развёрнут — `deepseek_pow_solver.wasm`
  необходим для PoW-задачи и находится вне `requirements.txt`.
- **`DB_PATH`** учитывается: укажите его на постоянный том, чтобы сохранять пул
  SQLite-токенов между пересборками контейнера.
- Сервер читает `PORT` из переменных окружения, поэтому любая платформа, которая
  подставляет порт, работает без изменений.

## Быстрый старт

### Локальный Python
```bash
python3 -m venv deeperseeker_env
source deeperseeker_env/bin/activate
pip install -r requirements.txt
cp .env.example .env
python3 app.py
```

> **Примечание:** Благодаря PR https://github.com/AmanCode22/deeperseeker/pull/16 от [@alan7383](https://github.com/alan7383), Playwright и Chromium устарели и оставлены как резервный вариант (DeepSeek не применяет AWS WAF к запросам с заголовками Android-клиента). Больше не нужно запускать `playwright install chromium` или `xvfb-run`, если вы не возвращаетесь к резервному механизму cookie. Также экономится память, и это гораздо стабильнее, чем сбор cookie.

### Docker / Podman (рекомендуется Podman для rootless-режима)

Указано в issue [#3](https://github.com/AmanCode22/deeperseeker/issues/3)

```bash
cp .env.example .env

# С использованием Podman (рекомендуется — rootless)
podman build -t deeperseeker .
podman run -d --name deeperseeker -p 4000:4000 --env-file .env deeperseeker

# С использованием Docker
docker build -t deeperseeker .
docker run -d --name deeperseeker -p 4000:4000 --env-file .env deeperseeker

# Или с помощью Podman Compose / Docker Compose
podman-compose up -d
# docker compose up -d
```

Примечание: `docker-compose.yml` привязан к `127.0.0.1:4000` (локальный доступ) — измените сопоставление портов, если нужно открыть наружу.

Дашборд: `http://localhost:4000/`

## Конфигурация (`.env`)

Скопируйте `.env.example` в `.env` и впишите свои секреты:

```bash
cp .env.example .env
```

| `PORT` | Порт сервера | `4000` |
| `DEEPSEEKER_MAX_HISTORY_TOKENS` | Лимит токенов для передаваемой истории при построении промпта первого сообщения | `24000` |

| `DEEPSEEKER_PER_TOOL_RESULT_TOKENS` | Лимит на каждый отдельный результат инструмента (чтобы один огромный вывод не съел бюджет) | `2000` |

## Настройка токена

1. Откройте приватное/инкогнито-окно -> `chat.deepseek.com` -> Войдите
2. Извлеките токен — **выберите способ по вашему устройству** (оба сохранены, работает любой):

   **A. ПК / Android (есть devtools)**: Консоль (F12) ->
   `JSON.parse(localStorage.getItem("userToken")).value`

   **B. iPhone / iPad (букмарклет Safari)**: на iOS нет консоли F12, а Safari отказывается
   выполнять `javascript:`, введённый в адресную строку — поэтому используйте сохранённую закладку:

   1. Safari: откройте любую страницу -> Поделиться -> **Добавить закладку** -> Сохранить
   2. Откройте список закладок -> **Изменить** эту запись -> замените её адрес кодом
      ниже (дайте узнаваемое имя, например `DS token`) -> Сохранить
   3. На `chat.deepseek.com` (вы авторизованы, страница полностью загружена) -> нажмите значок закладок ->
      нажмите `DS token`. Токен скопируется в буфер обмена и появится в alert-окне.

   ```javascript
   javascript:(function(){var t='';try{var r=localStorage.getItem('userToken');if(r){try{t=JSON.parse(r).value||r;}catch(e){t=r;}}}catch(e){alert('Не удалось прочитать: '+e.message);return;}if(!t||t.length<20){alert('Нет userToken. Убедитесь, что вы вошли на chat.deepseek.com и страница загрузилась.');return;}var a=document.createElement('textarea');a.value=t;a.style.cssText='position:fixed;left:-9999px';document.body.appendChild(a);a.select();a.setSelectionRange(0,999999);var ok=document.execCommand('copy');a.remove();alert((ok?'Скопировано в буфер\n\n':'Не удалось скопировать — скопируйте вручную долгим нажатием\n\n')+'длина '+t.length+'\n'+t.substring(0,12)+'...');})();
   ```

   > Пользователи Android тоже могут использовать этот букмарклет (свежие версии Chrome также
   > блокируют вставку `javascript:` в адресную строку) либо консоль F12 выше.

3. Вставьте строку сырого токена в Дашборд (`/dashboard`). Закройте приватное окно.

## Эндпоинты API и использование

- **OpenAI Base**: `http://localhost:4000/v1`
  - `POST /v1/chat/completions` (стриминг и обычный режим)
  - `POST /v1/responses` (Responses API)
  - `GET /v1/models`
  - `POST /v1/files`
  - `GET /v1/files/{file_id}`
  - `GET /v1/files/{file_id}/content`
- **Anthropic Base**: `http://localhost:4000`
  - `POST /v1/messages` (также на `/messages`)
  - `POST /v1/files/upload`
- **Ключ авторизации**: задаётся в `.env` (`DEEPSEEKER_API_KEY`)
- **Модель**: `v4.1flash` — единственная модель DeepSeek по умолчанию (vision-возможности: `vision` больше не требует отдельной модели). Каждый запрос обслуживается ею, какое бы значение `model` ни отправил клиент (устаревшие алиасы вроде `instant`, `expert`, `vision` и `anthropic/claude-*` принимаются и нормализуются в `v4.1flash`). Также значится как `anthropic/claude-v4.1flash` для автообнаружения клиентом Claude Desktop. Если `model` не отправлен, запросы по умолчанию идут на `v4.1flash`.

## Возможности

- **Пул из нескольких токенов**: случайная ротация активных токенов.
- **Сессионный селектор по контексту**: вычисляет SHA-256-подпись по канонизированной истории сообщений (до последнего хода ассистента), модели и скоупу API-ключа, чтобы находить и продолжать существующие сессии веб-чата. Создание сессий защищено блокировкой от дублей.
- **Политика «суммаризация-и-rollover» для контекста**: когда накопленный контекст сессии приближается к наблюдаемому лимиту запоминаемого контекста (~393К входных токенов), бридж просит модель сделать компактное передаваемое SUMMARY во «вспомогательном» чате, открывает новый веб-чат и засеивает его этим SUMMARY и новым сообщением пользователя. Соответствующие вызовы инструментов/результаты последнего обмена сохраняются (с ограничением `DEEPSEEKER_MAX_TOOL_RESULT_TOKENS` и более жёстким лимитом на результат через `DEEPSEEKER_PER_TOOL_RESULT_TOKENS`); приложения описываются словами внутри SUMMARY, а не пересылаются. Первый обмен — какого бы размера он ни был — никогда не подлежит rollover (путь первого сообщения принимает ~1М токенов). Заявленные лимиты в `/v1/models` (`context_window`, `max_output_tokens`) отражают это наблюдаемое поведение, а не гарантированные лимиты апстрима. Промпт SUMMARY требует от модели считать содержимое диалога данными, а не инструкциями.
- **Передача полной истории**: инъекция полной истории диалога в новые сессии, если подпись сессии отсутствует в БД или аккаунт переключён.
- **Автоматический обход rate-limit**: токены автоматически помечаются `RATE_LIMITED` при HTTP 401/403/429, выделяется новый токен, контекст (включая файлы) переносится, и чат бесшовно продолжается одной повторной попыткой.
- **Устойчивость к длинному контексту**: если веб-сессия апстрима падает или возвращает пустой ответ (например, переполнение контекста), битая сессия отбрасывается, а запрос повторяется один раз на новой сессии с уплотнённой, ограниченной по токенам инъекцией истории; неисправимые ошибки апстрима возвращаются корректными JSON-ошибками API вместо сырых 500.
- **Вызовы инструментов и стриминг**: стриминг через server-sent events (SSE) со сшиванием think-тегов по границам чанков (без обрезки) и парсингом tool-call в нескольких форматах — DSML XML, `<tool_call>` XML, блоки `<function_call>` и JSON — в схемы OpenAI/Anthropic.
- **Файлы и Vision**: извлечение изображений Base64/URL (с защитой от SSRF) и потоковая загрузка документов. Изображения и документы передаются напрямую через `ref_file_ids` — шаг форкания vision-файлов (`fork_file_task`) удалён, потому что `v4.1flash` нативно управляет vision.
- **Совместим с Claude Desktop**: богатые метаданные возможностей в `/v1/models` + алиас `anthropic/claude-v4.1flash` для автообнаружения клиентом.
- **Защищённый дашборд**: TTL сессии, блокировка при переборе пароля (5 попыток → 5 минут), проверка CSRF-источника.
