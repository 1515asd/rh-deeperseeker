Добавить токен доступа

Шаги:

  1. Откройте приватное/инкогнито-окно в браузере
  2. Зайдите на chat.deepseek.com и авторизуйтесь
  3. Извлеките токен — выберите способ по вашему устройству (оба сохранены, работает любой):

Способ A · ПК / Android (есть инструменты разработчика)

Откройте инструменты разработчика (F12) → Консоль (Console) → вставьте:

JSON.parse(localStorage.getItem("userToken")).value

Способ B · iPhone / iPad (команда «Быстрые команды») — рекомендуется, проверено на практике

Используйте действие «Выполнить JavaScript на веб-странице» в приложении «Быстрые команды» (Shortcuts). Оно имеет полный доступ к странице и, в отличие от закладки, не вызывает на iOS ошибку «The operation is insecure»:

  1. Приложение «Быстрые команды» → кнопка + справа вверху, создать новую → добавить действие «Выполнить JavaScript на веб-странице» → вставьте в поле скрипта:
var out = '';
try {
  var r = localStorage.getItem('userToken');
  if (r) { try { out = JSON.parse(r).value || r; } catch(e) { out = r; } }
} catch(e) { out = ''; }
if (out) { completion(out); } else { completion('Токен не получен: убедитесь, что вы вошли на chat.deepseek.com в Safari'); }
  1. Затем добавьте действие «Копировать в буфер обмена»
  2. Ключевой шаг (без него «команда выполнится, но результата не будет»): внизу отредактируйте блок получения («Показать в» / входящие) → тип «Веб-страница Safari», и убедитесь, что вход «Страница» у JS-действия подключён к предыдущему шагу
  3. Использование: откройте в Safari авторизованный chat.deepseek.com (после полной загрузки страницы) → нажмите Поделиться → Выполнить команду → токен попадёт в буфер обмена и появится во всплывающем окне
Способ C · Букмарклет Safari (запасной: на некоторых iOS возникает ошибка The operation is insecure — при её появлении используйте способ B)

iOS не позволяет выполнять javascript: прямо в адресной строке — закладка является единственным способом. Но на некоторых iOS чтение localStorage из скрипта закладки заблокировано (ошибка SecurityError, не связанная с настройкой «Блокировать все cookie») — при ошибке перейдите на способ B.

  1. Откройте в Safari любую обычную страницу → Поделиться → Добавить в закладки → Сохранить
  2. Список закладок → Изменить эту запись → целиком замените «Адрес» кодом ниже → Сохранить
  3. На авторизованной странице chat.deepseek.com нажмите на закладку → автоматическое копирование
javascript:(function(){var t='';try{var r=localStorage.getItem('userToken');if(r){try{t=JSON.parse(r).value||r;}catch(e){t=r;}}}catch(e){alert('Ошибка чтения: '+e.message+' (используйте способ B — Быстрые команды)');return;}if(!t||t.length<20){alert('userToken не найден. На Android также можно использовать закладку из способа C (новые версии Chrome тоже запрещают выполнение javascript: в адресной строке), либо продолжать пользоваться консолью F12.
