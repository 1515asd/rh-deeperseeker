添加认证令牌

步骤：

  1. 打开浏览器无痕/隐私窗口
  2. 访问 chat.deepseek.com 并登录
  3. 提取令牌 —— 按你的设备选一种方式（两套都保留，用哪套都行）：

方式 A · 电脑 / 安卓（有开发者工具）

打开开发者工具（F12）→ 控制台（Console）→ 粘贴：

JSON.parse(localStorage.getItem("userToken")).value

方式 B · iPhone / iPad（Safari 书签小工具）

iOS 上没有 F12 控制台，而且 Safari 不允许在地址栏直接执行 javascript:——只能用书签跑脚本：

  1. Safari 打开任意一个普通页面 → 点分享 → 添加到书签 → 存储
  2. 打开书签列表 → 编辑刚存的那条 → 把「地址」整段替换成下面这段代码（名称改成好认的，比如「取令牌」）→ 存储
  3. 在 chat.deepseek.com（已登录、页面完全加载后）→ 点书签图标 → 点「取令牌」→ 令牌自动复制到剪贴板并弹窗显示
javascript:(function(){var t='';try{var r=localStorage.getItem('userToken');if(r){try{t=JSON.parse(r).value||r;}catch(e){t=r;}}}catch(e){alert('读取失败: '+e.message);return;}if(!t||t.length<20){alert('未找到 userToken。请确认已登录 chat.deepseek.com 且页面已加载完成');return;}var a=document.createElement('textarea');a.value=t;a.style.cssText='position:fixed;left:-9999px';document.body.appendChild(a);a.select();a.setSelectionRange(0,999999);var ok=document.execCommand('copy');a.remove();alert((ok?'已复制到剪贴板 ✓\n\n':'复制失败，请手动长按复制\n\n')+'长度 '+t.length+'\n'+t.substring(0,12)+'...');})();
  1. 复制令牌并粘贴到下方
  2. 去掉两侧的引号——只粘贴令牌字符串本身
  3. 关闭无痕窗口（保留浏览器里的登录状态）
📱 iPhone 上书签报「The operation is insecure」？用快捷指令（推荐，已实测成功）

iOS Safari 的书签脚本可能被系统禁掉 localStorage（报 SecurityError，与「阻止所有 Cookie」无关）。用快捷指令的「在网页上运行 JavaScript」有完整页面权限，不受此限制：

  1. 快捷指令 App → 新建 → 添加操作「在网页上运行 JavaScript」→ 脚本框粘贴：
var out = '';
try {
  var r = localStorage.getItem('userToken');
  if (r) { try { out = JSON.parse(r).value || r; } catch(e) { out = r; } }
} catch(e) { out = ''; }
if (out) { completion(out); } else { completion('未取到：请确认 Safari 已登录 chat.deepseek.com'); }
  1. 再添加操作「拷贝至剪贴板」
  2. 关键：编辑快捷指令底部「接收」→ 类型选「Safari 网页」，并确认 JS 操作的「网页」输入已连上上一步（没连上会"运行完没结果"）
  3. 使用：Safari 打开已登录的 chat.deepseek.com → 分享 → 运行快捷指令 → 令牌进剪贴板

安卓也可以用方式 B 的书签（新版 Chrome 同样禁止在地址栏执行 javascript:），或继续用 F12 控制台。
