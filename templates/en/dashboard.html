Add Auth Token

Steps:

  1. Open an incognito/private browser window
  2. Go to chat.deepseek.com and log in
  3. Extract the token — pick the method matching your device (both are kept, either works):

Method A · Desktop / Android (has DevTools)

Open DevTools (F12) → Console → paste:

JSON.parse(localStorage.getItem("userToken")).value

Method B · iPhone / iPad (Shortcuts) — recommended, verified to work

Use the "Run JavaScript on Web Page" action in the Shortcuts app. It has full page access and, unlike a bookmark, does not trigger the iOS "The operation is insecure" error:

  1. Shortcuts app → + in the top-right corner, create new → add the action "Run JavaScript on Web Page" → paste into the script box:
var out = '';
try {
  var r = localStorage.getItem('userToken');
  if (r) { try { out = JSON.parse(r).value || r; } catch(e) { out = r; } }
} catch(e) { out = ''; }
if (out) { completion(out); } else { completion('No token: make sure you are logged in to chat.deepseek.com in Safari'); }
  1. Then add the action "Copy to Clipboard"
  2. Key step (without it "the shortcut runs but returns nothing"): at the bottom of the shortcut, edit the receiving input → type "Safari Web Page", and confirm the JS action's "Page" input is connected to the previous step
  3. Usage: open the logged-in chat.deepseek.com in Safari (after the page fully loads) → tap Share → Run Shortcut → the token lands on the clipboard and shows in a popup
Method C · Safari bookmarklet (fallback: some iOS builds report The operation is insecure — if so, use Method B)

iOS does not allow running javascript: directly in the address bar — a bookmark is the only entry point. But some iOS builds block localStorage reads from bookmarklet scripts (SecurityError, unrelated to the "Block All Cookies" setting) — if you hit an error, switch to Method B.

  2. Bookmarks list → Edit that entry → replace the entire "Address" with the code below → Save
  3. On the logged-in chat.deepseek.com page tap the bookmark → auto-copies
