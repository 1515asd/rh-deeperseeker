Добавить токен авторизации

Шаги:

  1. Откройте браузер в режиме инкогнито/приватном окне
  2. Перейдите на chat.deepseek.com и войдите в систему
  3. Извлеките токен — выберите один способ в зависимости от вашего устройства (оба варианта сохранены, можно использовать любой):

Способ A · Компьютер / Android (есть инструменты разработчика)

Откройте инструменты разработчика (F12) → консоль (Console) → вставьте:

JSON.parse(localStorage.getItem("userToken")).value

Способ B · iPhone / iPad (Быстрые команды) — рекомендуется, проверено на практике

Используйте «Выполнить JavaScript на веб-странице» в Быстрых командах. У неё есть полные права на страницу, и она не будет выдавать ошибку «The operation is insecure», как это бывает с закладками в iOS:

  1. Приложение «Быстрые команды» → в правом верхнем углу + создать → добавить действие «Выполнить JavaScript на веб-странице» → вставить в поле скрипта:
var out = ''; try { var r = localStorage.getItem('userToken'); if (r) { try { out = JSON.parse(r).value || r; } catch(e) { out = r; } } } catch(e) { out = ''; } if (out) { completion(out); } else { completion('未取到：请确认 Safari 已登录 chat.deepseek.com'); }
  1. Затем добавьте действие «Скопировать в буфер обмена»
  2. Ключевой шаг (если пропустить, «после запуска не будет результата»): отредактируйте внизу быстрой команды «Получать» → тип выберите «Веб-страница Safari» и убедитесь, что вход «Веб-страница» действия JS подключён к предыдущему шагу
  3. Использование: в Safari откройте уже авторизованный chat.deepseek.com (после полной загрузки страницы) → нажмите Поделиться → Запустить быструю команду → токен попадёт в буфер обмена и появится во всплывающем окне
Способ C · Закладка-скрипт в Safari (запасной: некоторые версии iOS выдают The operation is insecure, при ошибке используйте способ B)

iOS не позволяет выполнять javascript: прямо в адресной строке, закладка — единственный вход. Но некоторые версии iOS блокируют чтение localStorage из скрипта закладки (ошибка SecurityError, не связана с настройкой «Блокировать все cookie») — при ошибке переходите на способ B.

  1. В Safari откройте любую обычную страницу → Поделиться → Добавить в закладки → сохранить
  2. Список закладок → Изменить эту запись → полностью замените «Адрес» на код ниже → сохранить
  3. На уже авторизованной странице chat.deepseek.com нажмите закладку для запуска → автоматическое копирование
javascript:(function(){var t='';try{var r=localStorage.getItem('userToken');if(r){try{t=JSON.parse(r).value||r;}catch(e){t=r;}}}catch(e){alert('读取失败: '+e.message+'（请改用方式 B 快捷指令）');return;}if(!t||t.length<20){alert('未找到 userToken。请确认已登录且页面加载完成');return;}var a=document.createElement('textarea');a.value=t;a.style.cssText='position:fixed;left:-9999px';document.body.appendChild(a);a.select();a.setSelectionRange(0,999999);var ok=document.execCommand('copy');a.remove();alert((ok?'已复制到剪贴板 ✓\n\n':'复制失败，请手动长按复制\n\n')+'长度 '+t.length+'\n'+t.substring(0,12)+'...');})();

На Android тоже можно использовать закладку из способа C (новый Chrome также запрещает выполнение javascript: в адресной строке), либо продолжайте использовать консоль F12.
